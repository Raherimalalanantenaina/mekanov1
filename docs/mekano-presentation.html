4. Mode d’emploi — Client (automobiliste)

Trouver un garage

  1. Ouvrir l’onglet Liste ou Carte.
  2. Autoriser la localisation GPS pour le tri par distance.
  3. Utiliser la recherche ou un filtre (vidange, lavage…).
  4. Toucher une fiche pour voir détail, avis, horaires, photos.

Demander un devis

  1. Sur la fiche garage → Demander un devis.
  2. Saisir nom, téléphone, description (+ photo optionnelle).
  3. Suivre la conversation dans Demandes.
  4. L’historique reste en base et en cache local.

Prendre rendez-vous

  1. Sur la fiche → choisir un créneau RDV.
  2. Le garage accepte ou refuse dans son Inbox.
  3. Statut visible dans l’onglet Demandes → RDV.

Itinéraire & hors ligne

  1. Itinéraire : tracé routier vers le garage.
  2. Hors ligne : consultation du cache (liste / carte déjà vues).
  3. Bannière jaune = données en cache, pas de sync.

5. Mode d’emploi — Propriétaire de garage

Créer un compte

  1. Onglet Compte / Garage → Inscription.
  2. Email + mot de passe + nom.
  3. Attendre la validation admin par email (Valider / Refuser).
  4. Une fois approuvé → publier la fiche garage.

Publier / modifier la fiche

  1. Onglet Publier : nom, adresse, GPS, téléphone.
  2. Cocher les services (dont lavage).
  3. Ajouter jusqu’à 12 photos + tarifs + horaires.
  4. Enregistrer → validation admin si nouvelle fiche.

Gérer les clients

  1. Onglet Inbox : devis reçus + chat.
  2. Répondre (texte / photo) ou utiliser réponses rapides.
  3. Accepter / refuser les rendez-vous.
  4. Consulter les stats (vues, appels, recherches).

Règles importantes

  • 1 compte = 1 garage
  • Photos & conversations stockées en PostgreSQL
  • Compte non validé → impossible de publier
  • Garage non validé → invisible sur liste / carte
